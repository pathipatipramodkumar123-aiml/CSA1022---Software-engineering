# Example GitHub repository structure

```text
my-project/
├── README.md
├── .gitignore
├── package.json
├── src/
│   └── index.js
└── tests/
    └── index.test.js
```

- `README.md`: project title, description, setup steps and usage.
- `.gitignore`: excludes generated files, secrets and dependencies.
- `package.json`: Node.js project metadata and scripts.
- `src/`: application source code.
- `tests/`: automated tests.
